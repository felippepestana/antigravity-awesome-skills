# 🎓 Learning Guide: Master Antigravity Skills

**Welcome to your journey to becoming an AI-driven engineer.**

This guide is designed to take you from zero to total mastery of the 1006+ skills available in this repository. Don't try to learn everything at once; follow these phases to build a solid foundation.

---

## 🛤️ Learning Path

### 🟢 Phase 1: Foundations (The Awakening)

*Goal: Understand what skills are and how to invoke your first specialist.*

1. **What is a Skill?** Read [GETTING_STARTED.md](GETTING_STARTED.md) to understand the "Specialist on Demand" analogy.
2. **Invocation Syntax:** Learn to use the `@` symbol. Try typing `@brainstorming` in your AI chat right now.
3. **Environment Setup:** Ensure skills are in the correct folder (`.agent/skills`, `.claude/skills`, etc.).
4. **First Contact:** Use the `@brainstorming` skill to plan a simple feature (e.g., a todo list). Answer the AI's questions until you have a final spec.

### 🟡 Phase 2: The Swiss Army Knife (Core Toolkit)

*Goal: Integrate the 5 skills every modern developer needs to use daily.*

These skills form the "Essentials Pack":

1. **`@brainstorming`**: Always start here before writing the first line of code.
2. **`@concise-planning`**: Turn your brainstorm into an atomic, actionable checklist.
3. **`@writing-plans`**: Create detailed implementation plans for complex tasks.
4. **`@lint-and-validate`**: Keep your code clean by following professional standards automatically.
5. **`@systematic-debugging`**: When something breaks, don't "guess". Use this skill for a scientific investigation.

### 🟠 Phase 3: Role-Specific Mastery

*Goal: Master the toolset specific to your field.*

Choose your path in [BUNDLES.md](BUNDLES.md) and practice the recommended skills:

* **Web Wizard 🧙‍♂️**: `@react-best-practices`, `@tailwind-patterns`, `@frontend-design`.
* **Hacker Pack 🛡️**: `@ethical-hacking-methodology`, `@api-security-best-practices`.
* **Product Pack 🚀**: `@seo-audit`, `@marketing-psychology`, `@copywriting`.

### 🔴 Phase 4: Workflow Engine (Orchestration)

*Goal: Learn to chain multiple skills to perform complex tasks from start to finish.*

1. **Simple Chaining:** Learn to give double prompts: *"Use @brainstorming for design and then @test-driven-development to implement"*.
2. **Using Workflows:** Study [WORKFLOWS.md](WORKFLOWS.md). Try running the `ship-saas-mvp` workflow.
3. **File Context:** Learn to point the AI to specific files: *"Use @security-auditor on routes/auth.js"*.

### 🟣 Phase 5: Skill Alchemist (Advanced)

*Goal: Create your own tools and contribute to the community.*

1. **Skill Creation:** Use the `@skill-creator` skill to automate a repetitive process you do every day.
2. **Technical Anatomy:** Read [SKILL_ANATOMY.md](SKILL_ANATOMY.md) to understand how to write Markdown that AIs interpret best.
3. **Contribution:** Follow the contribution guide and submit your skill to this repository!

---

## 💡 Master Tips

1. **Answer one question at a time:** If a skill asks you 5 questions, answer only the first one or ask it to ask you one by one. This keeps the AI focused and accurate.
2. **Don't accept the first answer:** Skills are guides, not laws. If you disagree with a design pattern suggested by `@react-best-practices`, ask for a reasoned alternative.
3. **Keep the Catalog open:** Keep [CATALOG.md](../CATALOG.md) (or the Web App) open in a side tab. Whenever you feel you're doing something manually, look to see if there's a skill for it.
