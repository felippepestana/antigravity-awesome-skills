# 🎓 Guia de Aprendizado: Masterize as Antigravity Skills

**Bem-vindo à sua jornada para se tornar um engenheiro impulsionado por IA.**

Este guia foi desenhado para levar você do zero ao domínio total das mais de 1000 skills disponíveis neste repositório. Não tente aprender tudo de uma vez; siga estas fases para construir uma base sólida.

---

## 🛤️ Trilha de Aprendizado

### 🟢 Fase 1: Fundamentos (O Despertar)

*Objetivo: Entender o que são skills e como invocar seu primeiro especialista.*

1. **O que é uma Skill?** Leia o [GETTING_STARTED.md](GETTING_STARTED.md) para entender a analogia do "Especialista sob Demanda".
2. **Sintaxe de Invocação:** Aprenda a usar o símbolo `@`. Tente digitar `@brainstorming` no seu chat de IA agora mesmo.
3. **Configuração de Ambiente:** Garanta que as skills estão na pasta correta (`.agent/skills`, `.claude/skills`, etc.).
4. **Primeiro Contato:** Use a skill `@brainstorming` para planejar uma funcionalidade simples (ex: uma lista de tarefas). Responda às perguntas da IA até ter um spec final.

### 🟡 Fase 2: O Canivete Suíço (Core Toolkit)

*Objetivo: Integrar as 5 skills que todo desenvolvedor moderno precisa usar diariamente.*

Essas skills formam o "Essentials Pack":

1. **`@brainstorming`**: Sempre comece aqui antes de escrever a primeira linha de código.
2. **`@concise-planning`**: Transforme o seu brainstorm em uma checklist atômica e executável.
3. **`@writing-plans`**: Crie planos detalhados de implementação para tarefas complexas.
4. **`@lint-and-validate`**: Mantenha seu código limpo seguindo padrões profissionais automaticamente.
5. **`@systematic-debugging`**: Quando algo quebrar, não tente "adivinhar". Use esta skill para uma investigação científica.

### 🟠 Fase 3: Especialização por Role

*Objetivo: Dominar o conjunto de ferramentas específico para sua área de atuação.*

Escolha o seu caminho em [BUNDLES.md](BUNDLES.md) e pratique as skills recomendadas:

* **Web Wizard 🧙‍♂️**: `@react-best-practices`, `@tailwind-patterns`, `@frontend-design`.
* **Hacker Pack 🛡️**: `@ethical-hacking-methodology`, `@api-security-best-practices`.
* **Product Pack 🚀**: `@seo-audit`, `@marketing-psychology`, `@copywriting`.

### 🔴 Fase 4: Workflow Engine (Orquestração)

*Objetivo: Aprender a encadear múltiplas skills para realizar tarefas complexas do início ao fim.*

1. **Encadeamento Simples:** Aprenda a dar prompts duplos: *"Use @brainstorming para o design e depois @test-driven-development para implementar"*.
2. **Uso de Workflows:** Estude o [WORKFLOWS.md](WORKFLOWS.md). Tente rodar o workflow `ship-saas-mvp`.
3. **Contexto de Arquivos:** Aprenda a apontar a IA para arquivos específicos: *"Use @security-auditor no arquivo routes/auth.js"*.

### 🟣 Fase 5: Alquimista de Skills (Avançado)

*Objetivo: Criar suas próprias ferramentas e contribuir para a comunidade.*

1. **Criação de Skills:** Use a skill `@skill-creator` para automatizar um processo repetitivo que você faz todo dia.
2. **Anatomia Técnica:** Leia [SKILL_ANATOMY.md](SKILL_ANATOMY.md) para entender como escrever Markdown que as IAs interpretam melhor.
3. **Contribuição:** Siga o guia de contribuição e envie sua skill para este repositório!

---

## 💡 Dicas de Mestre

1. **Responda uma pergunta de cada vez:** Se a skill te fizer 5 perguntas, responda apenas a primeira ou peça para ela te perguntar uma por uma. Isso mantém a IA focada e precisa.
2. **Não aceite a primeira resposta:** As skills são guias, não leis. Se você discorda de um padrão de design sugerido pela `@react-best-practices`, peça uma alternativa fundamentada.
3. **Mantenha o Catálogo aberto:** Deixe o [CATALOG.md](../CATALOG.md) (ou o Web App) aberto em uma aba lateral. Sempre que sentir que está fazendo algo manualmente, procure se existe uma skill para isso.
